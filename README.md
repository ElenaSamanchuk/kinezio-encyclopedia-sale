# Энциклопедия тренера: акция 29–31 октября 2026

Код для Тильды (T123) и превью страницы kineziofitness.online/coach-encyclopedia

## Что вставлять в Тильду
Заменить содержимое существующих блоков T123 на файлы из `tilda/`:
- `блок-1-стили.html` — как 08.09, можно не трогать
- `блок-3-разметка-1440.html` — даты «до 31 октября», таймер до 31.10 23:59
- `блок-4-разметка-430.html` — то же для мобильной
- `блок-5-скрипт.html` — конец акции 31.10 23:59:59 МСК, старт 29.10 12:00 МСК

Блок 2/5 (шапка с меню) на живой странице не используется — там своё меню Тильды

## Как работает
- До `SALE_START_MS` (29.10 12:00) обычная цена 14 990, в момент старта страница сама перезагружается
- С 29.10 12:00 до `SALE_END_MS` (31.10 23:59:59): 12 990 вместо 14 990, таймер, плашки «до 31 октября», клиентам 4 990
- После конца — автоматически 14 990 / 5 990, плашки и таймер скрыты
- Сменить время старта: число `SALE_START_MS` в блоке 5 (`new Date("2026-10-29T12:00:00+03:00").getTime()`)
